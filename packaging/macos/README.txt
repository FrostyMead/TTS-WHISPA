Murmr for macOS
===============

1. Double-click "Install Murmr". If macOS says it can't check the app for malicious
   software (it isn't signed with a paid Apple developer account):
   System Settings > Privacy & Security > scroll down > "Open Anyway" next to Install Murmr.
2. A Terminal window installs Murmr (a few minutes). Murmr then appears in your menu bar.
3. Allow Murmr when macOS asks (Microphone, Input Monitoring, Accessibility), and set
   System Settings > Keyboard > "Press 🌐 key to" > Do Nothing.

Hold fn and talk; let go to type. Murmr updates itself.
More: https://github.com/FrostyMead/murmr
